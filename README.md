# Essence Salon POS
A new standalone React + Vite project for Essence Unisex Salon & Spa.

Features: POS checkout with multiple services, service catalogue, staff management and individual commission rates, 7.5% VAT, payment-method recording, printable receipts, sales history, dashboard, and CSV export.

## Cloudflare Pages
Build command: `npm run build`
Build output directory: `dist`

## Important
Sales are stored in this browser's local storage, not in a cloud database. Export sales regularly. Payment methods are recorded but no bank or payment gateway is connected. VAT and commission rules should be confirmed for your business.
